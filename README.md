Nesse repositorio coloquei em prática a integração do JAVA com o banco de dados MYSQL. 
Essa exemplo foi feito junto com o professor Nelio da plataforma de cursos da Udemy.
Nesse Projeto consegui evoluir no java e consegui entender na prática o uso de coleções para usar junto com o banco de dados.
O projeto tem como objetivo conectar com o banco de dados e usar o PreparedStatement e o ResultSet para para integrar com o MYSQL.
Sem dúvidas foi um divisor de águas na minha trilha em java. Com certeza fez toda diferença no meu aprendizado.
